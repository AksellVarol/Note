# 📓 دفترچه یادداشت

یک دفترچه یادداشت تک‌فایل و آفلاین به زبان فارسی، که بدون اینترنت هم روی گوشی کار می‌کند.

## قابلیت‌ها

- یادداشت متنی با عنوان، دسته‌بندی و رنگ
- عکس همراه یادداشت: از گالری، با دوربین، یا اسکن با فیلتر سیاه‌وسفید
- یادداشت صوتی با ضبط از میکروفون
- چک‌لیست تعاملی (خط‌هایی که با `- [ ]` شروع می‌شوند، تیک می‌خورند)
- الگوهای آماده: جلسه، لیست خرید، خاطرات روزانه، درس، ایده، چک‌لیست
- سنجاق کردن یادداشت‌ها، مرتب‌سازی، جستجو و فیلتر
- یادآوری با بنر بالای صفحه، صدا، یا اعلان سیستمی
- قفل با رمز ۴ رقمی، حالت مخفی با صفحه قفل شبیه ماشین‌حساب، و قفل خودکار بعد از ۵ دقیقه بی‌کاری
- سطل زباله با امکان بازگردانی، و انیمیشن پاک شدن با پاک‌کن 🧽
- رنگ‌بندی دلخواه بخش‌ها (سربرگ، پس‌زمینه، دکمه‌ها، کارت‌ها) با چند تم آماده از جمله تم گرادیانی «باحال»
- دسترسی سریع با دکمه شناور +
- خروجی و ورودی JSON برای پشتیبان‌گیری و انتقال یادداشت‌ها

## استفاده

فایل `notebook-app.html` را در مرورگر گوشی باز کن. یادداشت‌ها در مرورگر همان دستگاه ذخیره می‌شوند.

برای اینکه مثل یک اپ روی صفحه اصلی گوشی باشد، در مرورگر گزینه «Add to Home Screen» را بزن.

## حریم خصوصی

یادداشت‌ها فقط روی دستگاه خودت می‌مانند و به هیچ سروری فرستاده نمی‌شوند. قفل اپ جلوی نگاه اتفاقی دیگران را می‌گیرد، ولی رمزنگاری کامل فایل نیست.
